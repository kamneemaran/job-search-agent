## 🔧 TECHNICAL DETAILS

### Scraper Types Implemented

1. **HTTP Request + BeautifulSoup** (Works best)
   - Indeed, LinkedIn, SAP Jobs Board
   - No JavaScript needed
   - Fastest & most reliable

2. **Playwright Browser Automation** (JS rendering)
   - EURES, CV.lt, Hays, Michael Page
   - Handles JavaScript-rendered content
   - Slower, more resource-intensive
   - Had issues with EPIPE errors on some boards

3. **Direct URLs** (Manual/Helper)
   - CV.lt direct search URL provided
   - Google search with site: operator
   - Quick reference for manual searches

### Known Issues & Workarounds

| Issue | Boards | Cause | Solution |
|-------|--------|-------|----------|
| 403 Forbidden | Stepstone, Robert Walters | Bot detection | Add rotating headers, proxy rotation |
| 404 Not Found | Heidrick & Struggles | Wrong API endpoint | Locate correct search URL |
| Timeout | eJob.de | Slow server | Increase timeout to 15-20s |
| EPIPE errors | Hays, Michael Page | Playwright connection loss | Restart browser, use connection pool |
| No results | Dice | Job type mismatch (ABAP vs MM) | Filter by role type before scraping |
